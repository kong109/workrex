workrex ships prebuilt binaries for macOS on Apple Silicon (`darwin-arm64`) and
Linux on x86_64 (`linux-amd64`). On other platforms,
[build from source](#build-from-source).

workrex installs as `workrex`, so it does not replace an upstream `workmux`
binary. To run agents in Rex, you also need Rex. See the
[Rex installation docs](https://www.superlogical.com/rex/docs/).

## Install script

The install script downloads the latest release for your platform, checks its
SHA-256 checksum, and puts `workrex` in `/usr/local/bin`, or in `~/.local/bin`
when `/usr/local/bin` is not writable.

```bash
curl -fsSL https://raw.githubusercontent.com/kong109/workrex/main/scripts/install-workrex.sh | bash
```

To pick the directory, set `WORKMUX_INSTALL_DIR`. To pin a release, set
`WORKMUX_VERSION`:

```bash
curl -fsSL https://raw.githubusercontent.com/kong109/workrex/main/scripts/install-workrex.sh | WORKMUX_VERSION=v0.1.278-rex.1 bash
```

workrex keeps the workmux names for its environment variables and
[configuration](/guide/configuration/) files, so existing workmux setups work
unchanged.

## Release tarball

Each [release](https://github.com/kong109/workrex/releases) has a
`workrex-<platform>.tar.gz` and a matching `.sha256` file. This example installs
the macOS build. For Linux, use `workrex-linux-amd64` and `sha256sum -c`.

```bash
curl -fsSLO https://github.com/kong109/workrex/releases/latest/download/workrex-darwin-arm64.tar.gz
curl -fsSLO https://github.com/kong109/workrex/releases/latest/download/workrex-darwin-arm64.sha256
shasum -a 256 -c workrex-darwin-arm64.sha256
tar -xzf workrex-darwin-arm64.tar.gz
mv workrex ~/.local/bin/
```

## Build from source

Building needs Rust. Install it with [rustup](https://rustup.rs/) if you don't
have it. The Cargo package keeps the upstream name `workmux`, so name the
binary:

```bash
cargo install --git https://github.com/kong109/workrex --bin workrex
```

## Update

To update a binary from the install script or a tarball, run
[`workrex update`](/reference/commands/update/). For a source build, run the
`cargo install` command again.

## Shell alias

To type less, alias `workrex` to `wm` in your `.bashrc`, `.zshrc`, or other
shell configuration file:

```bash
alias wm='workrex'
```

## Shell completions

To complete commands and branch names, add the line for your shell to its
configuration file.

## Uninstall

The uninstall script runs `workrex uninstall`, which removes the status hooks
and skills that `workrex setup` installed, workrex's state directory, and its
update cache. Then the script deletes the binary from `/usr/local/bin`,
`~/.local/bin`, and `~/.cargo/bin`. To see what `workrex uninstall` would remove,
run `workrex uninstall --dry-run`.

```bash
curl -fsSL https://raw.githubusercontent.com/kong109/workrex/main/scripts/uninstall-workrex.sh | bash
```

The script keeps `~/.config/workmux/`, because workrex and upstream workmux both
read it. Delete it yourself only if you use neither. Remove the completion line
and the `wm` alias from your shell configuration. To find worktrees that
are still on disk, run `git worktree list`.
